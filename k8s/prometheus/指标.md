






## k8s指标
### container_memory_rss 指标
经过container_memory_rss采集的指标一般比top现实的rss要小，因为两者采集的数据不一样，要以container_memory_rss为准，K8s是否告警以及是否驱逐一个pod都是采用的这个指标

`anon` 代表**匿名内存**，这正是我们通常理解的“程序运行实际占用的内存”（即 RSS 的核心部分）。它包括：
- **堆 (Heap)**：程序动态分配的内存（如 `malloc` 或 `new`）。
- **栈 (Stack)**：线程栈。
- **匿名映射**：使用 `mmap` 分配的未关联文件的内存区域。

**关键点：**  
在 Cgroup V2 的定义中，`anon` 内存是**不可被文件系统回收的**。如果内存不够了，内核不能像清理文件缓存那样直接丢弃它，必须通过 Swap 交换出去或者触发 OOM。这与 Cgroup V1 中 `rss` 的特性完全一致。

```go
  
func setMemoryStats(s *cgroups.Stats, ret *info.ContainerStats) {  
	...
    if cgroups.IsCgroup2UnifiedMode() {  
       ret.Memory.Cache = s.MemoryStats.Stats["file"]  
       ret.Memory.RSS = s.MemoryStats.Stats["anon"]     // 在cgroupv2中，采集的时anon字段作为rss，更加符合rss定义
       ret.Memory.Swap = s.MemoryStats.SwapUsage.Usage - s.MemoryStats.Usage.Usage  
       ret.Memory.MappedFile = s.MemoryStats.Stats["file_mapped"]  
    } else if s.MemoryStats.UseHierarchy {  
       ret.Memory.Cache = s.MemoryStats.Stats["total_cache"]  
       ret.Memory.RSS = s.MemoryStats.Stats["total_rss"]  
       ret.Memory.Swap = s.MemoryStats.Stats["total_swap"]  
       ret.Memory.MappedFile = s.MemoryStats.Stats["total_mapped_file"]  
    } else {  
    }  
    ...  
}
```
