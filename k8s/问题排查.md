## 因为污点问题调度失败
1. 先查看Node的污点(Taints字段)
```bash
# 查看Taints字段
kubectl describe nodes cn-hz-xxx-xx.xx.xx.xx 
```
2. 对应的pod声明为可以容忍对应的污点即可调度到对应的节点上
3. 如果是直接声明为不可调度，但是又想调度到这个节点上，可以使用 `operator: Exists` 声明，该声明能够容忍，集群中任意一个由管理员手动添加的自定义污点
例如最常见的master不可调度
```bash
# node中
Taints:      node-role.kubernetes.io/master:NoSchedule
```
要是想要调度到这个节点上，可以声明污点容忍为
```bash
tolerations:
  - operator: Exists
```
