


## 路由
### 查看路由
```bash
show ip route
```


## interface
### 查看网口信息

```bash
show ip interface brief
```


### 将网口的MTU配置为1500
```bash
enable 
configure terminal
interface Vlan20
  mtu 1500 
exit
end
```


### 配置网口进行镜像抓包
```bash
ceos>enable
ceos#configure terminal
ceos(config)#monitor session sniff source Ethernet1 both
ceos(config)#monitor session sniff destination cpu
ceos(config)#end
ceos#show monitor session

Session sniff 
------------------------

Sources:

Both Interfaces:        Et1

Destination Ports:

    Cpu :  active (mirror0)
```


```bash
bash 
tcpdump -i mirror0 -n icmp or port 6443
```

### 关闭网口镜像
```bash
enable
configure terminal
no monitor session sniff 
end
```


## BGP

### 查看bgp总结信息
```bash
show ip bgp summary
```

### 查看bgp邻居详情
```bash
show ip bgp neighbors
```


### 配置等同多路径
```bash
config t
router bgp 65001
  maximum-paths 4
```


### 查看对应宣告信息的bgp信息
```bash
show ip bgp 172.16.0.240/28
```
