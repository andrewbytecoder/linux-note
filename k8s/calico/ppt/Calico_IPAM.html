01为什么 IPAM 至关重要？

Kubernetes 中每个 Pod 都需要唯一的 IP 地址才能与其他 Pod 和服务通信

1 · 动态 Pod 创建
Pod 是短暂的（ephemeral），被频繁创建和销毁。每个新 Pod 都需要从集群地址空间中获取一个可用 IP。
2 · 避免 IP 冲突
没有正确的 IPAM，多个 Pod 可能被分配相同的 IP，导致网络冲突和通信失败。
3 · 高效地址分配
IPAM 系统以「块」为单位向节点分配 IP 地址，减少逐个 IP 请求的开销，提升可扩展性。
4 · 跨节点通信
不同节点上的 Pod 需要集群内可路由的 IP，才能不经 NAT 直接通信——IPAM 通过合理的子网分配使之成为可能。
Calico 的 IPAM 通过向节点预分配 IP 块来实现高效分配，在保持全集群地址管理的同时，实现快速的 Pod 启动。

03默认 IP 池与 CIDR 选择

来自 custom-resources.yaml 的 Calico Installation 配置

默认 IP 池 CIDR
192.168.0.0/16
提供 65,536 个 IP 地址，足以支撑大规模集群
块大小 Block Size
/26 = 64 IPs
以 /26 块为单位，按需分配给节点

避免冲突 —— CIDR 不得与以下重叠

  • 宿主机（host machine）网络
  • Kubernetes Service CIDR —— 10.96.0.0/16
  • 任何已存在的 VPN 或企业网络网段
规模换算： /16 网段配合 /26 块 ≈ 可容纳 1,024 个节点（65536 ÷ 64），适用于大多数实验与生产环境。

kubectl get blockaffinities
NAME                                     AGE

  • BlockAffinity 资源表示 IPAM 块到节点的分配关系
  • 命名规则：ipam-block-affinity-<block-cidr-with-dashes>-<prefix-length>
  • Calico 按需为每个节点分配 /26 块（每块 64 个 IP）

07详细块亲和性（YAML）

kubectl get blockaffinities -o yaml

BlockAffinity
apiVersion: crd.projectcalico.org/v1
kind: BlockAffinity
metadata:
  name: ipam-block-affinity-192-168-0-64-26
spec:
  cidr: 192.168.0.64/26
  deleted: false
  node: calico-ipam-control-plane
  state: confirmed
字段含义
spec.cidr分配给节点的 IP 块，如 192.168.0.64/26
spec.node拥有该 IP 块的 Kubernetes 节点
spec.stateconfirmed=已生效在用；pending=分配进行中
spec.deleted该块是否被标记删除

10Pod IP 来自节点的块

每个 Pod 都被分配一个来自所在节点 CIDR 块的 IP（如 192.168.93.200/32 来自块 192.168.93.0/26）—— 这正是 Calico 按节点分配 IP 块以实现高效路由的体现。

11总结

IP Pools
大 CIDR 网段（如 192.168.0.0/16），定义整体地址空间
IP Blocks
从 IP 池中切分出的较小子网（如 /26 块），分配给节点
Block Affinity
IP 块与节点之间的分配（绑定）关系
IPAM
当 Pod 被创建时，Calico 在已分配的块内自动管理 IP 分配
一句话： Calico 把大地址池切成 /26 小块「批发」给各节点，节点再「零售」给 Pod —— 既快，又不会冲突。

12故障排查

如果遇到 IP 分配问题，按以下顺序排查

1 · 检查块是否充足
确认节点是否已分配到足够的 IP 块
2 · 检查 Calico Pod
kubectl get pods -n calico-system
3 · 检查节点状态
kubectl get nodes
4 · 查看日志
kubectl logs -n calico-system -l k8s-app=calico-node
troubleshooting
kubectl get pods -n calico-system
kubectl get nodes
kubectl logs -n calico-system -l k8s-app=calico-node
