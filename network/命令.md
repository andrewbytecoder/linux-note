### 监听网络变化
#### 实时显示本机网络对象（地址、路由、链路、邻居等）的增删改变化
用来监听网络变化，查看CNI等插件，是如何实现将集群内部的网络打通的。
```bash
> docker exec -it pod-routing-worker bash
root@pod-routing-worker:/# ip monitor all

[NSID]nsid 1 (iproute2 netns name: cni-87f5fd12-9b17-a0c9-0424-a500c0ecedc5)
[LINK]4: cali11b46e7e389@if3: <BROADCAST,MULTICAST> mtu 1500 qdisc noop state DOWN group default 
    link/ether ee:ee:ee:ee:ee:ee brd ff:ff:ff:ff:ff:ff link-netns cni-87f5fd12-9b17-a0c9-0424-a500c0ecedc5

```

| **<br><br>对象<br><br>** | **<br><br>说明<br><br>**   |
| ---------------------- | ------------------------ |
| `link`                 | 网卡状态（up/down）、MTU、MAC 变化 |
| `address`              | IP 地址的添加 / 删除            |
| `route`                | 路由表变化（新增 / 删除 / 修改）      |
| `neigh`                | ARP / NDP 邻居表变化          |
| `rule`                 | 策略路由规则变化                 |
| `mroute`               | 多播路由                     |
| `nsid`                 | network namespace ID 变化  |


`[NETCONF]` -- 网络协议栈参数变化
`[LINK]` -- 网卡（接口）声明周期
`[NSID]` -- 网络命名空间
`[ADDR]` -- ip地址
`[ROUTE]` -- 路由表变化
`[NEIGH]` -- ARP/FDR 邻居
