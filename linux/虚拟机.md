### 通过命令配置管理网络—另一种方式
可以通过如下方式修改
```bash
nano /etc/network/interfaces
```
配置示例如下：
```bash
1. `auto lo`
2. `iface lo inet loopback`

3. `auto eno1`
4. `iface eno1 inet manual`

5. `auto vmbr0`
6. `iface vmbr0 inet manual`
7. `bridge-ports eno1 # 桥接到物理网卡`
8. `bridge-stp off`
9. `bridge-fd 0`
10. `bridge-vlan-aware yes`
11. `bridge-vids 2-4094`

12. `auto vmbr0.40`
13. `iface vmbr0.40 inet static`
14. `address 10.161.40.31/24`
15. `gateway 10.161.40.1`

16. `source /etc/network/interfaces.d/*`
```

**可能用到的操作**

```bash
1. `# 1. 登录 Proxmox SSH 或直接访问控制台`
2. `ssh root@your-proxmox-ip`

3. `# 2. 备份原始配置`
4. `cp /etc/network/interfaces /etc/network/interfaces.bak`

5. `# 3. 编辑配置文件`
6. `nano /etc/network/interfaces`

7. `# 4. 修改：`

8. `# 5. 保存并退出编辑器`

9. `# 6. 重启网络服务`
10. `systemctl restart networking`

11. `# 或重启网络接口`
12. `ifdown vmbr0 && ifup vmbr0`
13. `ifdown vmbr0.40 && ifup vmbr0.40`
```


### 交换机
交换机上配置trunk模式，并允许vlan通过
```bash
1. `interface GigabitEthernet0/0/14`
2. `port link-type trunk`
3. `port trunk allow-pass vlan 2 to 4094`
```
